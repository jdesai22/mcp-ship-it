# node-mcp-server\n\nMinimal Node.js MCP server implementing the official Model Context Protocol (https://modelcontextprotocol.io) for Windsurf troubleshooting.\n\n## Endpoints\n\n- `GET /` : MCP-compliant ServiceStatus\n- `POST /context` : Upload a MCP ContextDocument (see spec)\n- `GET /context` : List all ContextDocuments\n- `GET /events` : SSE EventStream (heartbeat)\n\n## ContextDocument Example\n\n```json\n{\n  "id": "doc-001",\n  "type": "text",\n  "content": "This is a sample context doc.",\n  "created_at": "2025-04-19T13:53:44Z"\n}\n```\n\n## Setup & Run\n\n```sh\ncd node-mcp-server\nnpm install\nnpm start\n```\n\nServer runs on `http://localhost:3000` by default.\n\n## Example Usage\n\n- Upload context:\n  ```sh\n  curl -X POST -H "Content-Type: application/json" -d '{"id":"doc-001","type":"text","content":"hello"}' http://localhost:3000/context\n  ```\n- List context:\n  ```sh\n  curl http://localhost:3000/context\n  ```\n- SSE:\n  Open `http://localhost:3000/events` in your browser or use `curl`.\n\n---\n\nSee https://modelcontextprotocol.io for full protocol details.\n
